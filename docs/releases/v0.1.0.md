# Orbis v0.1.0（Phase 1）

Phase 1 的第一個發布版本，對應 PLAN.md 的 M3。

## 內容

- **Task 生命週期**：
  - Backlog → Ready → Planning → Plan Gate → Running → Verifying → Review Gate → PR Open → Done（ARCHITECTURE §5）。
  - Verification 超過重試上限時，由人決定再試、略過或中止。
  - Review Gate 的 diff 為空時改為「結束（沒有變更）」。
- **Runner**：
  - Local Runner（Desktop sidecar）與 Team Runner（Docker）。
  - 以 git worktree 隔離。
  - Permission Policy 與 `allow_commands` 的參數辨識。
  - Windows 強化：中文與空白路徑、長路徑、刪除重試、WSL git、三種 shell、休眠後重連、保留 port。
- **Agent**：
  - Claude Code、Codex、Antigravity、Grok Build（ACP）。
  - Delegation（`consult`／`branch`）與 Orbis MCP。
- **GitHub**：
  - Issues 雙向同步、開 PR。
  - Feedback Loop：review 留言與 CI 失敗時自動修正並 push，沿用 Worktree 時對齊遠端分支。
- **協作**：
  - 共同編輯 Task 描述與 Repo Spec。
  - @mention、通知中心與桌面通知。
  - Preview 與元素留言。
- **部署與發布**：
  - `deploy/docker-compose.yml`（Postgres、Server 加 Web、選用的 Team Runner）。
  - Desktop 安裝檔：Windows NSIS、macOS dmg／zip，都不簽章。
  - Windows 從 public GitHub Releases 自動更新。
  - 版本不相容時明確提示要更新哪個元件。
- **測試**：
  - Windows、macOS 的 CI，以及完整系統 e2e。
  - 真實 Agent 煙霧測試：`scripts/smoke-agents.ps1`，2026-10-25 實機 4／4 通過。

安裝與部署見 [INSTALL.md](../INSTALL.md)，Desktop 見 [DESKTOP.md](../DESKTOP.md)，煙霧測試見 [SMOKE-TEST.md](../SMOKE-TEST.md)。

## M3 驗收清單

用 Windows Sandbox（或 Hyper-V VM）當乾淨的客戶端，Server 部署在主機的 Docker，**只照 INSTALL.md 操作**：

1. 主機：照 INSTALL.md §2–§6 完成：
   - 建置 image；
   - 建立 OAuth App 與 GitHub App；
   - 填 `deploy/.env`；
   - `docker compose up`，第一次以 bootstrap owner 登入。

   `ORBIS_PUBLIC_URL` 用主機的區域網路 IP（§6.4）。
2. 主機：用 §11 的 `gh webhook forward` 轉送 webhook。
3. 主機：建立 Project、登記測試 Repo，安裝 GitHub App。
4. Sandbox：安裝 Desktop。
   - 安裝檔取自 release workflow 的 artifact，或 draft Release。
   - 遇到 SmartScreen 時選「其他資訊 → 仍要執行」。
   - 設定 Server URL 並登入，確認系統匣顯示 Local Runner 已連線。
5. 建立 Task → 派工到「我的電腦」的 Claude Code → 處理權限請求 → 在 Review Gate 核准 → 自動開 PR → 在 GitHub merge → Task 自動轉 Done。
6. 結果記在這個檔案的「驗收紀錄」。

## 移到 Phase 2

- **Runner 與部署**：
  - Team Runner 改用 GitHub App installation token 代為 push；目前用 Docker secret 傳入的 PAT。
  - Team Runner 支援 Antigravity 與 Grok Build。
  - 容器隔離與 `yolo`。
  - image 發布到 GHCR；Server image 瘦身。
  - Server 的 secret 也改用 Docker secret。
  - 反向代理與 TLS 的範例、託管部署文件。
  - Runner 在 WSL 內的實機驗證；實機休眠喚醒的驗證。
- **Desktop**：
  - macOS 簽章、公證與自動安裝更新；Windows 簽章。
  - App 圖示。
  - Release notes 自動產生，以及 pre-release 通道。
  - 自動更新的實機驗證：要等 v0.1.0 之後的下一版才能做。
- **UI 與流程**：
  - Worktree 的手動封存與保留期限。
  - Run 以「結束（沒有變更）」結束時的狀態改為 completed，需要新的 RunControl。
  - AC 表單精準判斷 Repo 是否有 `[verify].commands`。
  - Needs You 直接做 Verification 的決定。
  - Task note 的 UI。
  - 桌面通知的系統層驗證。
  - CI 修正 prompt 中的步驟名稱。
- **新工作區介面**：依 `design_handoff_orbis_workspace` 原型重做 Web UI，已在 v0.1.0 之後開發。原型中後端還沒有的功能另見後端開發規劃。
